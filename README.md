# 🥁 Drum Kit

A fun and interactive **Drum Kit** web application built using **HTML**, **CSS**, and **JavaScript**. Tap your keyboard or click on the drum buttons to play different drum sounds!

🚀 [Live Demo](https://naflanmohamed.github.io/Drum-Kit/)

## 🎯 Features

- Responsive UI with animated drum buttons
- Keyboard and mouse interaction
- Real drum sound effects
- Simple and lightweight design

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

## 🎹 How to Use

1. Open the [Live Demo](https://naflanmohamed.github.io/Drum-Kit/)
2. Press the keys `c`, `h`, `k`, `o`, `b`, `r`, `s`, `t`, `e`   on your keyboard
3. Or click the buttons on the screen
4. Enjoy the beat! 🥁
